# Phase 3A Strategy Learning Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Read-only, reproducible paper-account analytics and chronological evaluation foundation, never live optimization.

**Architecture:** Standalone stdlib module reads one SQLite snapshot with mode=ro and query_only. Reconstruct weighted-average flat-to-flat position episodes and compare recorded realized amounts, residual positions, settlement totals and account identity. Separate completed-trade statistics from realized events. Entry-filter cohort evaluation preserves recorded execution costs and excludes boundary-crossing markets/trades; it is not a portfolio replay.

**Tech Stack:** Python >=3.12, sqlite3, Decimal, argparse, unittest; no new dependencies.

**Spec:** User's Phase 3A request; implementation decisions and data inventory in `docs/phase-3a-analytics.md`.

- Partial exits followed by unresolved settlement must not become completed trades.
- Legacy/missing settlement or observation fields must not become zero-cost or inferred payouts.
